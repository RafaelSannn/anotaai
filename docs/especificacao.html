1. Visão Geral do Sistema

O Anotaai é uma plataforma web de conexão entre prestadores de serviço e clientes. Possui dois perfis de usuário:

  • Visitante — pessoa física que busca serviços, publica demandas e envia mensagens para empresas.
  • Empresa — prestadora de serviços que cria um perfil público, exibe publicações e responde a visitantes via chat.

Funcionalidades principais

MóduloFuncionalidade
AutenticaçãoCadastro, login com BCrypt, logout via localStorage
PerfilFoto de perfil em Base64, nome, localização, categoria, descrição
PublicaçõesCRUD de publicações com imagem; feed por tipo de autor
ExplorarListagem e filtro de empresas por categoria
ChatMensagens diretas com suporte a texto e imagem em Base64

5.3 Instalação do MySQL 8.0 (Ubuntu/Debian)

sudo apt update
sudo apt install mysql-server

# Iniciar e habilitar
sudo systemctl start mysql
sudo systemctl enable mysql

# Verificar status
sudo systemctl status mysql

5.4 Configuração do Banco de Dados

# Acessar o MySQL como root
sudo mysql

# Criar usuário dedicado e conceder permissões
CREATE USER 'anotaai'@'localhost' IDENTIFIED BY 'anotaai123';
GRANT ALL PRIVILEGES ON anotaai.* TO 'anotaai'@'localhost';
FLUSH PRIVILEGES;
EXIT;
O banco anotaai é criado automaticamente pelo Spring Boot na primeira inicialização graças ao parâmetro createDatabaseIfNotExist=true na URL JDBC. As tabelas também são criadas/recriadas automaticamente pelo Hibernate (ddl-auto=create).

5.5 Configuração da Aplicação

Arquivo: src/main/resources/application.properties

spring.datasource.url=jdbc:mariadb://localhost:3306/anotaai?createDatabaseIfNotExist=true&allowPublicKeyRetrieval=true
spring.datasource.username=anotaai
spring.datasource.password=anotaai123

spring.jpa.hibernate.ddl-auto=create
spring.jpa.show-sql=true
spring.jpa.database-platform=org.hibernate.dialect.MySQLDialect

server.tomcat.max-http-form-post-size=20MB
spring.servlet.multipart.max-file-size=20MB
spring.servlet.multipart.max-request-size=20MB
ddl-auto=create recria todas as tabelas a cada inicialização, apagando os dados existentes. Em produção, mude para update para preservar os dados.

6.4 Arquivo de Propriedades de Produção

Crie /opt/anotaai/application-prod.properties no servidor:

spring.datasource.url=jdbc:mariadb://localhost:3306/anotaai?createDatabaseIfNotExist=true&allowPublicKeyRetrieval=true
spring.datasource.username=anotaai

spring.jpa.show-sql=false

server.port=8080
server.tomcat.max-http-form-post-size=20MB
spring.servlet.multipart.max-file-size=20MB

Segurança: Nunca commite senhas de produção no repositório Git. Use variáveis de ambiente ou arquivos externos ao projeto.

6.5 Executar o JAR no Servidor

# Copiar o JAR para o servidor
scp target/anotaai-0.0.1-SNAPSHOT.jar usuario@servidor:/opt/anotaai/

# No servidor, executar
java -jar /opt/anotaai/anotaai-0.0.1-SNAPSHOT.jar \
     --spring.config.location=/opt/anotaai/application-prod.properties

6.6 Executar como Serviço systemd (recomendado)

Criar o arquivo /etc/systemd/system/anotaai.service:

[Unit]
Description=Anotaai - Plataforma de Serviços
After=network.target mysql.service

[Service]
User=anotaai
WorkingDirectory=/opt/anotaai
ExecStart=/usr/bin/java -jar /opt/anotaai/anotaai-0.0.1-SNAPSHOT.jar \
          --spring.config.location=/opt/anotaai/application-prod.properties
SuccessExitStatus=143
Restart=on-failure
RestartSec=10

[Install]
WantedBy=multi-user.target

# Habilitar e iniciar o serviço
sudo systemctl daemon-reload
sudo systemctl enable anotaai
sudo systemctl start anotaai

# Verificar status e logs
sudo systemctl status anotaai
sudo journalctl -u anotaai -f

6.7 Nginx como Proxy Reverso (opcional)

Configuração em /etc/nginx/sites-available/anotaai:

server {
    listen 80;
    server_name seu-dominio.com.br;

    # Aumentar limite para suportar imagens Base64 de 20MB
    client_max_body_size 25M;

    location / {
        proxy_pass http://localhost:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}

sudo ln -s /etc/nginx/sites-available/anotaai /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
